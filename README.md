# Geypal Investment Platform Prototype

A responsive front-end prototype for a Geypal investment platform with:
- Sign up and sign in flows
- Google/Apple alternatives
- Dashboard with current Naira balance
- Fixed bottom navigation for Deposit, Withdraw, Plans, and Profile
- Deposit selection from ₦15,000 to ₦205,000
- Withdraw selection from ₦10,000 to ₦5,000,000
- Payment instructions page with the account details:
  - Account name: Godsfavour Ekette
  - Account Number: 3237527067
  - Bank name: First Bank of Nigeria
- Plans view with 10-day lease and 150% profit model
- Profile screen with personal details

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a front-end prototype designed to match the requested functionality and user flow. It simulates live updates in the browser without connecting to a banking or payment API.
